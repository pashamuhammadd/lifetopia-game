# Contributing (draft)
Open an issue or discuss a proposed change before substantial work. Use a feature branch, narrowly scoped commits, include `.meta` files, and document test evidence, screenshots where appropriate and limitations. Never commit generated caches, secrets, personal data or assets without clear rights. Keep public discussion free of private vulnerability details. Owner review required for changes to packages, architecture, licenses, scope, deployments and integrations. Contribution licensing terms are not yet finalized; check with owner before accepting external code or artwork.
