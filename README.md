# Lifetopia World — Unity game client

A tropical cozy life simulation and social sandbox. Explore, play, connect and create. Built with Unity 2D and a 2.5D illustrated Island Explorer visual direction. Browser desktop and mobile are targets; multiplayer and optional Solana features are future milestones.

**Status:** revival / foundation. No playable feature or Web performance is claimed until verified.

## Development
- Unity 6.3 LTS (6000.3.29f1), Web Build Support, Git and Git LFS.
- Clone, run `git lfs pull`, open project in Unity Hub using the pinned version. Unity CLI/MCP optional for AI-assisted development; follow official installation instructions.
- Read `CLAUDE.md` and `Documentation/DECISIONS.md`; development gates in `Documentation/DEVELOPMENT-ROADMAP.md`.
- Build Web via Unity Build Profiles; use local HTTP serving. Build output is not source-controlled.
