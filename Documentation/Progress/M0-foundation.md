## 4. Web Build Profile and build
- Build target switched Windows → **Web (WebGL)** via the CLI target switch; Web profile scene list overrides the global list with only `FoundationSmoke`.
- Output `Builds/Web/Smoke` (git-ignored). BuildReport: **Succeeded, 0 errors, 0 warnings**, ~21 min first build (IL2CPP; later builds use cache).
- Output size 8.6 MB on disk; compressed transfer ≈ 8.7 MB (wasm 6975 KB, data 1656 KB, framework 74 KB, loader 27 KB) — under the 25 MB draft target for an empty scene; real content will change this.
- Compression: Brotli (project default, unchanged). Served through a local `127.0.0.1` Python server that sends `Content-Encoding: br` (plain `python -m http.server` cannot serve Brotli builds correctly). Never `file://`, never deployed.
- Editor note: "Pipeline: this build does not include the Pipeline" — expected; the AI-automation runtime is excluded from player builds.
